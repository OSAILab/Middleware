7.4.0 (2026-11-16) HTTP 匹配样本预览与安全删除

交付方式：默认客户支持包仅含 Windows x86 SDK、一份双语离线文档、发布说明及 Android GitHub / JitPack 获取入口，不包含 Android AAR 或 Android SDK ZIP。Windows x64 HTTPS 单独提供，Win7 验证包供目标机验收；Android 通过 OSAILab/Middleware 的 GitHub / JitPack 渠道获取，接入前确认所选版本的标签、构件及依赖可以下载。Android 普通 / HTTP 及设备档位以相应 Release 和接入说明为准，不汇总进客户支持包。

1. 不新增 HTTP 路由，仅增强三个既有接口：普通同步 recognition 显式 include_sample=1 返回最终 SKU 对应的真实代表样本 id/sample_token/source；get/picture 增加 view=preview 缩略图与缺图状态；delete/picture 增加与旧 ids 互斥的 items 校验删除。
2. 识别、预览和增强删除均同步返回。增强删除在同一事务内校验全部身份、删除特征及相关面积长宽比记录、写索引增量并更新受影响 SKU 的动态阈值，随后同步发布索引／阈值并清除旧识别学习上下文。明确返回提交与运行态恢复状态；图片暂不能清理时在后续启动或增强删除重试，不增加任务轮询接口或定时线程。
3. 保留旧参数必填规则、默认响应及公共 C++/JNI 签名；自动识别、WebSocket、图片测试与旧识别别名不扩展。校验阻止 FIFO 覆盖、编号复用及正式整库恢复后的旧请求误删，不降级为裸 id 删除。
4. 特征容量与图片配额分别生效。默认 20 条动态特征、保存 5 张动态图时，增强预览仍列出全部 20 条记录，15 条无图记录保留身份并可删除；删除无图特征不误删其余图片。增强删除继续保护共享引用和外部导入源文件。
5. 删除成功后回收有效索引编号；缓存重载从实际墓碑恢复复用队列，避免反复删除补学累积节点。排除仍被数据库占用、0 和学习接口范围外编号；重建回退不加入失效槽位，旧 sample_token 不能删除复用编号后的新样本。
6. 首次升级仅补 fresh 私有身份元数据，不重写原特征、日期、模型信息或全库索引增量，不改变 HNSW 格式／缓存键，不因身份迁移强制全量构图。兼容共享缓存 writer 的末尾空行，保留非空损坏数据及 ABI／模型／容量等校验。整库导入携带的旧图片清理待办随图库身份原子作废。
7. 用户文档、双语 OpenAPI／机器索引与 Middleware 版本同步为 7.4.0，补充 20/5 缺图管理、直接校验删除、重试与恢复边界。Android 本地交付须替换完整 AAR 并重编宿主 APK。

验证记录：源码专项已覆盖真实存图配额、缺图查询删除、128 次真实 ANN 删除补学、8 次缓存重启、事务回滚与旧 token 拒绝；本轮最终构件、哈希与门禁以 reports/release-7.4.0-20261116/ 为准。生产 SDK 继续排除未启用的 quality 实现及质量账本。
